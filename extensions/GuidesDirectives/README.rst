===========================================
phpDocumentor Guides Directives Extension
===========================================

This repository is a read-only subsplit of `phpDocumentor's monorepo <https://github.com/phpDocumentor/phpDocumentor>`__,
where it lives at ``extensions/GuidesDirectives``. It is automatically published here so it can be required
independently via Composer.

**Do not open pull requests or issues on this repository.** Any changes made here will be overwritten the next
time the subsplit runs. Please make your changes, report bugs, and open pull requests on the
`phpDocumentor monorepo <https://github.com/phpDocumentor/phpDocumentor>`__ instead, under
``extensions/GuidesDirectives``.
