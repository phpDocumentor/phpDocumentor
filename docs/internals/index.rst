.. title:: Internals 2

Internals
=========

In this section of you will find more information about the internals of phpDocumentor as a project. Reading these
docs will help you to understand how the project is managed. And what the most important parts of phpDocumentor do.
The docs can be interesting for anyone working on the codebase of phpDocumentor.

Start with :doc:`architecture` for a high-level map of the application's main subsystems and how they work together.
From there, follow the links to the :doc:`flow` and :doc:`pipeline` pages for more detail on how the system processes
input and produces output.
